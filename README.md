# SmartShop Assistant 🛍️
AI-powered e-commerce chatbot built with LangChain, ChromaDB, and Groq.

## Tech Stack
- LangChain
- ChromaDB  
- Groq (LLaMA 3.1)
- HuggingFace Embeddings
- Python 3.11

## Setup
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Create `.env` file: `GROQ_API_KEY=your_key_here`
4. Run: `python 07_langchain_rag.py`

## Features
- RAG pipeline with ChromaDB vector store
- LLaMA 3.1 powered responses
- Interactive chat loop
- E-commerce knowledge base
